US Fraud Servicing – Release Announcement

Fraud Case Management – Pega Enhancement & Defect Fixes

CHG1018852441 (07:30 22/05/2025 to 15:30 22/05/2025)

Release Announcement:

We are happy to announce the successful rollout of our first regularly scheduled bi-monthly Pega Release.

This release addresses 8 Incident, defect fixes & enhancements, improving the agent experience as well as Pega performance. For a more detailed breakdown see the “New Functionality Released” and “Incident Fixes Released” sections below.

Release Scope & Benefits:
  • Access groups with elevated security: User security with elevated permissions has been addressed and this will strengthen the overall application security score.
  • SLA Automation on Quality Fraud: Enabling SLA based automation for Quality Fraud assignment sets will reduce the agent overhead and increase chargeback volumes.
  • Enhancing Adhoc Case Processing: Enriching Adhoc case by fetching merchant information to facilitate tagging and will reduce agent overhead as this will reduce switching application between TSYS and Pega.
  • Custom Report: Enabling custom report functionality to Managers to create new own reports will provide greater flexibility to operation managers as they can build their own reports within Pega without any code changes.
Fixes for below production issues:
  • INC1038844639: Case Feeder logic is addressed to provide accurate set of Dispute based on the Account level Fraud Balance.
  • INC1038758697: RegZ finality date calculation has been addressed for Adhoc cases and helps in being compliant with RegZ regulations.
  • INC1038768404: Case reconciliation batch process is addressed to handle non purchase transactions.
  • INC1038597014: False negatives encountered as part of VISA validations is being addressed & will improve automated chargeback volumes.
  • INC1038733941: Exception handling mechanism for Account level change of Fraud process is updated to present valid Account Level details.
  • INC1039508409: Intelligent exception handling mechanism for Mastercard services are introduced and this will avoid issues during transaction being reported to Mastercard.
  • INC1037550736: Invalid scheduled items are being removed from Pega SLA Queue.
